# ربات تلگرامی برنامه‌ریزی و مدیریت کار تیمی

دستیار برنامه‌ریز شخصی + برد کانبان تیمی (مثل Trello) داخل تلگرام؛ فارسی، با تقویم شمسی.
هر کاربر یک **فضای شخصی خصوصی** دارد و می‌تواند عضو چند **تیم** باشد. اعلان‌ها (اساین، پاس‌دادن، بازبینی،
انجام، یادداشت، موعد) با دکمه‌های اقدام سریع مستقیم در تلگرام می‌رسد.

## اجرا
```bash
pip install -r requirements.txt   # Python 3.9+
cp .env.example .env              # BOT_TOKEN را از @BotFather بگذارید
python -m planner_bot.main
```
دیتابیس نسخه‌های قبلی خودکار به فضای شخصی منتقل می‌شود.

## افزودن کار
`/add گزارش فروش #کار !فوری ~2h @ali *هفتگی | فردا 18:30`
- `#دسته` · `!فوری|!مهم|!عادی` · `~2h` یا `~30m` تخمین زمان · `@عضو` مسئول (`@-` بدون مسئول؛ پیش‌فرض خودتان)
- `*روزانه|*هفتگی|*ماهانه` تکرار (با انجام‌شدن، نوبت بعدی ساخته می‌شود)
- زمان: امروز، فردا، شنبه…، `۱۴۰۵/۰۸/۱۵ 14:00`، `۲ ساعت دیگر`

## برنامه من (دستیار شخصی)
`/today` `/week` `/all` (کارهای من در همه فضاها، مرتب با اولویت و حجم کار تخمینی) · فیلتر با دسته یا نام فضا:
`/today ورزش`، `/week شرکت` · `/stats` · `/cats` `/cat ورزش 💪` · `/morning 07:30` `/evening 21:00`
(برنامه صبحگاهی و مرور شبانه) · `/import` (برنامه هفته از مارک‌داون)

## تیم و برد
| دستور | کار |
|---|---|
| `/team نام` | ساخت تیم (سازنده مدیر است) · `/invite` لینک دعوت · `/members` |
| `/ws` | فضای فعال (شخصی/تیم‌ها)؛ `/add` و `/board` روی فضای فعال کار می‌کنند |
| `/board [نام]` `/boards` `/newboard نام` | نمایش کانبان؛ لیست‌ها: بک‌لاگ ← برای انجام ← در حال انجام ← بازبینی ← انجام شد |
| `/card 12` | جزئیات و دکمه‌ها: انجام، شروع، لیست بعد، پاس، حذف |
| `/due` `/title` `/pri` `/move` `/pass` `/note` `/del` | ویرایش، جابه‌جایی، پاس‌دادن، یادداشت، حذف (سازنده/مدیر) |
| `/kick @x` `/role @x admin` `/leave` `/log` | مدیریت اعضا و تاریخچه فعالیت |

## ورود برنامه با مارک‌داون (`/import`)
```md
## شنبه
- [ ] 07:00 ورزش #ورزش !مهم
- 09:00-11:00 کار عمیق #کار ~2h
## ۲۵ مهر
- قرار دکتر #شخصی
## کار
- یکشنبه 14:30 جلسه تیم @sara
```
عنوان روز (شنبه…، فردا، `۱۴۰۵/۰۷/۲۵`، `۲۵ مهر`) روز می‌دهد و عنوان‌های دیگر دسته‌اند. آیتم بدون ساعت یادآوری
ندارد. ورود مجدد همان متن، موارد تکراری را رد می‌کند.
